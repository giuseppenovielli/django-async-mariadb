# Installation & setup

## Installation

```bash
pip install "django-async-mariadb[mysqlclient]"
```

The package uses {pypi}`asyncmy` for asynchronous connections and
{pypi}`mysqlclient` for the synchronous Django compatibility path. If the
native client cannot be installed, use the optional pure-Python fallback:

```bash
pip install "django-async-mariadb[pymysql]"
```

Enable pooling with the database `OPTIONS` setting.

### Versioning

The package depends heavily on the Django version, because a large part of it
is autogenerated from Django's own source. This release is generated from and
targets the Django `5.2.x` series.
See [Code generation](contribute.md#code-generation).

## Django settings

Set the database engine to the async backend:

```python
DATABASES = {
    "default": {
        "ENGINE": "django_async_mariadb.db.backends.mariadb",
        "NAME": "mydb",
        "USER": "app",
        "PASSWORD": "...",
        "HOST": "127.0.0.1",
        "PORT": "3306",
        "OPTIONS": {"pool": {"minsize": 1, "maxsize": 10}},
        "CONN_MAX_AGE": 0,
        ...
    },
}
```

```{note}
**This is a safe change for existing projects.** The backend is fully
compatible with Django's default `django.db.backends.mysql`: it subclasses
it and falls back to that implementation for everything synchronous. Your
existing sync ORM code — `Model.objects`, migrations, the admin, management
commands — keeps working unchanged, so you can switch the engine and adopt the
async API gradually rather than all at once.
```

Make sure `django_async_mariadb` — and any other required apps — are listed in
`INSTALLED_APPS`:

```python
INSTALLED_APPS = [
    ...
    "django_async_mariadb",
    ...
]
```

### Request signals

On startup the app connects `close_old_async_connections` to Django's
`request_started` and `request_finished` signals, so async connections are
released at the boundaries of every request and returned to the
[pool](connections.md#connection-pooling). No extra setup is required.

```{warning}
To disable the `request_started` and `request_finished` signals, set
`ASYNC_BACKEND_DISABLE_REQUEST_SIGNALS = True` in `settings.py`, and manually
connect them in your app's `ready` method if required.
```
